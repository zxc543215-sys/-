# Market Intelligence Terminal Pro

A comprehensive financial market intelligence system combining AI-powered news analysis, political insider tracking, and multi-currency portfolio management.

## Features

- **🤖 AI-Powered News Analysis**: Gemini-enhanced financial news with sentiment analysis and impact scoring
- **🏛️ Political Radar**: Track Congressional stock trades and Trump family portfolio movements
- **💼 Multi-Asset Portfolio Tracker**: Real-time P&L for Taiwan stocks, US stocks, and mutual funds
- **⚡ Auto-Updated Data Pipeline**: GitHub Actions CI/CD refreshes data every 5 minutes
- **📊 Dark Terminal UI**: Professional trading dashboard with Tailwind CSS

## Architecture

```
┌─ Frontend (Next.js + React)
│  └─ Dashboard → Real-time portfolio & news display
│
├─ Backend APIs (Next.js Route Handlers)
│  ├─ /api/data/news → Aggregated news with AI analysis
│  ├─ /api/data/political → Trump family & Congress trades
│  └─ /api/portfolio/calculate → Multi-asset P&L calculation
│
├─ Data Pipeline (Python + GitHub Actions)
│  ├─ Finnhub API → Market news
│  ├─ Gemini AI → Sentiment & impact analysis
│  └─ House Stock Watcher → Congressional trades
│
└─ Storage (JSON files in public/data/)
   ├─ news.json
   └─ political_radar.json
```

## Setup

### 1. Environment Variables

Create `.env.local`:
```env
GEMINI_API_KEY=your_gemini_api_key
FINNHUB_API_KEY=your_finnhub_api_key
NEXT_PUBLIC_USD_TWD_RATE=32.2
```

Add GitHub Secrets:
- `GEMINI_API_KEY`
- `FINNHUB_API_KEY` (optional for enhanced news)

### 2. Install Dependencies

```bash
npm install
pip install requests google-generativeai
```

### 3. Run Development

```bash
npm run dev
```

Visit `http://localhost:3000`

## Performance Considerations

- **API Caching**: 5-minute TTL for news & political data
- **Retry Logic**: 3 attempts with exponential backoff (500ms → 2s → 8s)
- **Error Boundaries**: Graceful degradation if data APIs fail
- **Lazy Loading**: News feed and portfolio sections load on-demand
- **Rate Limiting**: Respects Finnhub/Gemini API quotas

## Security

- API keys stored in GitHub Secrets (never in code)
- Next.js route handlers validate request origins
- CORS configured for public data endpoints
- No sensitive data in client-side bundles
